# Contributing

Contributions are welcome under the MIT License.

- **Bug reports:** describe what you expected, what happened, and the steps to reproduce it. Include relevant redacted error messages, but no Telegram session files, credentials, phone numbers, or private chat data.
- **Feature suggestions:** explain the problem the feature would solve and how you expect it to work.
- **Pull requests:** keep changes focused, describe their effect, and avoid adding personal Telegram data or runtime files.
- **Development setup:** create a Python 3.10+ virtual environment, install the pinned dependencies with `python -m pip install -r requirements.txt`, and run the application with `python main.py`. No comprehensive automated test suite is currently provided.

Never include `Data/`, `Downloads/`, `Logs/`, `.session` files, or personal Telegram data in an issue, branch, or pull request.

Do not post private credentials, API hashes, proxy passwords, Telegram session files, or personal Telegram data in issues or pull requests.
